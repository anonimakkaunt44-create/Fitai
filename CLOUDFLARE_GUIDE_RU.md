# 📱 Пошаговая инструкция запуска FitAI через Cloudflare с iPhone

Эта инструкция написана простым языком специально для управления **с телефона iPhone через браузер Safari или Chrome**. Вам **не нужно** писать код или открывать терминал на компьютере.

---

## 📋 План запуска:
1. Загрузка проекта в GitHub
2. Создание постоянной базы данных **Cloudflare D1**
3. Создание хранилища фотографий **Cloudflare R2**
4. Применение SQL-структуры (миграции)
5. Создание и подключение Worker в Cloudflare
6. Добавление секретов (API ключей)
7. Привязка D1 и R2 к приложению
8. Настройка Telegram Webhook одной ссылкой
9. Проверка работы бота и Mini App

---

## ШАГ 1: Загрузка проекта в GitHub

1. Откройте **Safari** на iPhone и перейдите на [github.com](https://github.com).
2. Зайдите в свой репозиторий с проектом **FitAI**.
3. Загрузите файлы этого обновлённого проекта в ветку `main`.
4. Теперь весь код готов к развертыванию.

---

## ШАГ 2: Вход в Cloudflare и создание базы данных D1

1. В Safari откройте [dash.cloudflare.com](https://dash.cloudflare.com) и войдите в свой аккаунт.
2. В левом верхнем углу нажмите кнопку меню **☰** (три полоски).
3. Нажмите раздел **Storage & Databases** (Хранилище и базы данных) ➡️ **D1 SQL Database**.
4. Нажмите синюю кнопку **Create database** (Создать базу данных).
5. В поле **Database name** введите точное имя:
   ```text
   fitai-db
   ```
6. Нажмите **Create** (Создать).
7. На открывшейся странице вашей новой базы данных вы увидите поле **Database ID** (длинная строка вида `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`). 
   *Скопируйте этот ID или оставьте вкладку открытой.*

---

## ШАГ 3: Применение SQL-структуры (Миграции) в D1

1. Находясь на странице базы `fitai-db` в Cloudflare, нажмите вкладку **Console** (Консоль) вверху.
2. В открывшееся поле ввода SQL вставьте текст из файла `migrations/0001_initial_schema.sql` (из вашего репозитория).
3. Нажмите кнопку **Execute** (Выполнить). Вы увидите зеленую галочку успеха.
4. *(Если у вас есть старые пользователи)*: Аналогично скопируйте текст из файла `migrations/0002_import_existing_data.sql` и нажмите **Execute**. Все пользователи, история и настройки сохранятся навсегда!

---

## ШАГ 4: Создание хранилища фотографий R2

1. Снова нажмите меню **☰** (три полоски) слева вверху.
2. Выберите **Storage & Databases** ➡️ **R2 Object Storage**.
3. Нажмите синюю кнопку **Create bucket** (Создать бакет).
4. В поле **Bucket name** введите:
   ```text
   fitai-photos
   ```
5. В блоке Location выберите **Automatic** (Автоматически).
6. Нажмите кнопку **Create bucket**. Хранилище готово!

---

## ШАГ 5: Подключение проекта и создание Worker

1. Нажмите меню **☰** ➡️ **Compute (Workers & Pages)**.
2. Нажмите **Create application** (Создать приложение).
3. Выберите вкладку **Workers** ➡️ введите имя:
   ```text
   fitai-telegram-app
   ```
4. Нажмите **Deploy** (Развернуть).
5. Теперь нажмите **Edit code** или вернитесь в список Workers и нажмите на `fitai-telegram-app`.

*(Самый удобный способ публикации — автоматический через GitHub)*:
В разделе Worker перейдите во вкладку **Settings** ➡️ **Build & Deploy** ➡️ **Build source** ➡️ нажмите **Connect GitHub** и выберите ваш репозиторий.
- **Build command** (Команда сборки): `npm run build:cf`
- **Output directory** (Папка сборки): `dist`
- **Package manager**: `npm` (будет выбран автоматически благодаря согласованному файлу `package-lock.json`).

> 💡 **Важно**: В проекте используется надежный **npm** с файлом `package-lock.json`. Старый несовместимый файл `bun.lock` (который вызывал ошибку `UnknownLockfileVersion` в Cloudflare) удален. Теперь Cloudflare выполняет быструю чистую установку через `npm ci`.

---

## ШАГ 6: Привязка D1 и R2 к Worker

1. На странице вашего воркера `fitai-telegram-app` нажмите вкладку **Settings** (Настройки).
2. Нажмите подраздел **Bindings** (Привязки).
3. **Привязка D1**:
   - Нажмите **Add** ➡️ выберите **D1 database**.
   - **Variable name**: введите строго большими буквами:
     ```text
     DB
     ```
   - **D1 database**: выберите из списка `fitai-db`.
   - Нажмите **Save**.
4. **Привязка R2**:
   - Нажмите **Add** ➡️ выберите **R2 bucket**.
   - **Variable name**: введите строго большими буквами:
     ```text
     BUCKET
     ```
   - **R2 bucket**: выберите из списка `fitai-photos`.
   - Нажмите **Save**.

---

## ШАГ 7: Добавление секретов (API ключей)

В этой же вкладке **Settings** нажмите подраздел **Variables and Secrets** (Переменные и секреты).
Для каждого пункта нажимайте **Add** ➡️ выбирайте тип **Secret**:

1. `GEMINI_API_KEY`
   - *Значение:* ваш API-ключ Gemini из [aistudio.google.com](https://aistudio.google.com/app/apikey).
2. `TELEGRAM_BOT_TOKEN`
   - *Значение:* токен вашего бота от @BotFather (например: `7812345678:AAH...`).
3. `TELEGRAM_ADMIN_CHAT_ID`
   - *Значение:* ваш числовой Telegram ID (узнать в Telegram через бота `@userinfobot`).
4. `ADMIN_USERNAMES`
   - *Значение:* ваш Telegram никнейм без `@` (например: `luckmepubg`).
5. `INITIAL_ADMIN_PASSWORD`
   - *Значение:* придумайте надежный пароль для входа в веб-панель администратора (логин: `admin`).
6. `JWT_SECRET`
   - *Значение:* любая случайная строка (например: `fitai_secure_token_key_998877`).
7. `TELEGRAM_WEBHOOK_SECRET`
   - *Значение:* любая случайная строка из английских букв и цифр для защиты вебхука (например: `fitaiSecretWebhookToken2025`).
8. `APP_URL`
   - *Значение:* адрес вашего воркера (например: `https://fitai-telegram-app.ВАШ-САБДОМЕН.workers.dev`).

Нажмите **Save and Deploy** (Сохранить и опубликовать).

## ШАГ 8: Настройка Telegram Webhook (Одной ссылкой прямо из Safari)

Чтобы бот получал сообщения и нажатия кнопок от пользователей, Telegram должен знать адрес вашего Cloudflare Worker.

Вставьте в адресную строку Safari следующую ссылку, заменив значения в скобках на свои:

```text
https://api.telegram.org/bot<ВАШ_TELEGRAM_BOT_TOKEN>/setWebhook?url=https://<ВАШ_WORKER_URL>/api/telegram/webhook&secret_token=<ВАШ_TELEGRAM_WEBHOOK_SECRET>
```

**Пример готовой ссылки:**
```text
https://api.telegram.org/bot7812345678:AAHTestToken12345/setWebhook?url=https://fitai-telegram-app.my-subdomain.workers.dev/api/telegram/webhook&secret_token=fitaiSecretWebhookToken2025
```

Откройте эту ссылку в Safari. Telegram ответит:
```json
{"ok": true, "result": true, "description": "Webhook was set"}
```
Поздравляем! Вебхук активирован с криптографической защитой от подделки запросов.

---

## ШАГ 9: Проверка работы

1. Откройте вашего бота в Telegram и отправьте команду `/start`.
2. Бот мгновенно пришлет приветственное сообщение с кнопкой **«🚀 Открыть FitAI Mini App»**.
3. Нажмите на кнопку: откроется красивое приложение FitAI с вашим профилем.
4. Проверьте:
   - Ввод параметров (вес, рост, цель);
   - AI-тренера (задайте любой вопрос);
   - Анализ еды по фото (фотография сохранится в Cloudflare R2, а калории запишутся в D1);
   - Все данные сохраняются навсегда и больше никогда не сбросятся!
